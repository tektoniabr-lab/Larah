# Althea — imagens geradas

34 de 34 imagens do planejamento geradas a partir de [02-inventario-imagens-e-prompts.md](../docs/02-inventario-imagens-e-prompts.md).

Os arquivos I01–I19 correspondem às fichas do inventário. Os 15 arquivos G correspondem aos prompts gráficos da seção 7. Os dois prompts-base orientam as séries; não representam duas imagens extras.

Todos os arquivos desta pasta são novas gerações em PNG, mantidas nas dimensões nativas entregues pelo gerador. Os originais permanecem em `docs/referencias/assets/`. Nenhum arquivo do site foi substituído.

Use a [galeria local](galeria.html) para comparar as imagens sobre fundos claro, pervinca e escuro. O [manifesto](manifesto.json) registra prompt do documento, dimensões, alfa e SHA-256 de cada arquivo. Os JSON de planejamento e prompts-base preservam as instruções de referência; o manifesto não pretende ser uma transcrição dos argumentos internos completos de cada chamada.

O mapa I02 é uma aproximação artística e requer teste/alinhamento no shader antes do uso. As setas, máscaras, logos e demais gráficos gerados são raster; para geometria exatamente igual à referência, os SVG e fontes originais continuam disponíveis. Os mestres I07/I08 não foram redimensionados para variantes artificiais: produzir versões menores a partir de um único mestre durante a integração. A imagem social X01 não possui referência visual nem prompt de reprodução no inventário e não integra os 34 pedidos.

**Revisão da máscara I19:** foram feitas duas gerações. A segunda eliminou o vazado central da primeira, mas ainda contém variações de tom/alfa; para o recorte exato, usar o [SVG original](../docs/referencias/assets/9O8sLldl6mV9miUVjkyrhGJsZ7c__q8307f77b.svg). A tentativa anterior está separada em `rascunhos/` e não integra o pacote principal. Ícones e recortes em PNG também devem ter as bordas conferidas antes da implementação.
